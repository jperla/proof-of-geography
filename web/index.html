Core Guarantees & Limits

        
    
          
  • Raw Vacuum c₀ Outer Bound (Default): Zero empirical RTT deductions; folds in clock resolution, drift, WGS84 chord-to-arc, and anchor-coordinate uncertainty. Never narrows via calibration.
    • 
          
  • Correlated Spatial Likelihood Map: Uses a spatially correlated covariance matrix so clustered anchors sharing network backbones do not manufacture false certainty. Supports single or multiple peaks labeled More likely / Less likely.
    • 
          
  • Fleet-Wide Hardware TEE Invariant: Software/dev anchors are excluded from production membership and never silently substituted when quorum is unmet.
    • 
          
  • Separate Coordinate Provenance: Hardware identity proves enclave code and key custody — never physical coordinates, which require separate audited provenance and cross-cloud speed-of-light checks.
